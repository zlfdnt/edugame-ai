# EduGame AI — Frontend

Generator game interaktif untuk guru SD & SMP. Frontend statis (HTML/CSS/JS murni) yang berbicara dengan backend Google Apps Script lewat `fetch`.

- Panduan lengkap: **PANDUAN-INSTALASI.md**
- Konfigurasi publik: `js/config.js` (isi `GAS_URL`; jangan taruh rahasia di sini)
- Tanpa `GAS_URL` aplikasi berjalan dalam **mode demo** (data di browser).

Struktur:
```
index.html
css/style.css
js/  config • art • content • ui • api • cursor • games • app • pages-public • pages-guru • pages-admin
```
Folder ini adalah root repository GitHub (jalankan `git init` DI SINI).
